# ProjetoPortfolioSCTEC

Projeto desenvolvido durante a trilha de **16 horas de desenvolvimento web do SCTEC**, com foco na construção de uma página de portfólio utilizando tecnologias fundamentais do Front-End.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3

## 📚 Objetivo do projeto

O objetivo deste projeto foi praticar conceitos essenciais do desenvolvimento web, como:

- Estruturação de páginas com HTML
- Estilização e layout com CSS
- Organização de conteúdo em uma página de portfólio
- Publicação do projeto utilizando GitHub Pages

## 🚀 Aprendizados

Durante o desenvolvimento deste projeto foi possível praticar:

- criação da estrutura semântica de uma página
- estilização de elementos e organização visual
- publicação de um projeto na web
